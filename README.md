# Black Myth: Wukong Benchmark — автоматизированный запуск (CPU + GPU)

Инструмент на C# для автоматизированного запуска **Black Myth: Wukong Benchmark Tool** из Steam.
Скрипт выполняет **два прохода** бенчмарка — CPU-тест и GPU-тест — с разными настройками графики, дожидается завершения каждого и выводит распарсенные результаты в консоль.

README.md

## Как запустить

1. Склонируйте репозиторий.
2. **Запустите Visual Studio от имени администратора** (иначе запись в `Program Files (x86)` будет запрещена).
3. Запустите проект (F5 / Ctrl+F5).
4. Дальше всё автоматически:
   - создаётся бэкап оригинального `GameUserSettings.ini` (файл `.bak`),
   - применяется CPU-профиль → запускается бенчмарк через Steam → ожидание ~4 мин,
   - делается скриншот экрана результатов → OCR → парсинг,
   - процесс игры закрывается,
   - применяется GPU-профиль → повторный запуск → ожидание,
   - INI восстанавливается из бэкапа,
   - в консоль выводится итоговая таблица.

> Общее время работы ~10–12 минут (по 4–5 минут на проход + паузы).
